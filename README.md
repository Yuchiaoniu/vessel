# Universal-Agent

這是一個具備智商 300 邏輯的自舉虛擬機。

### 如何運作：
1. **開起一個 Issue**：在標題寫下你的目標，內容寫下詳細需求。
2. **自我進化**：GitHub Actions 會喚醒 Gemini，Gemini 會寫出解決該 Issue 所需的腳本並在虛擬機中執行。
3. **成果保存**：所有的產出都會自動 Commit 回這個 Repo 或在 Issue 下方回覆。

### 指令範例：
- "幫我寫一個 Python 爬蟲並把結果存成 CSV"
- "幫我分析這個 Repo 的結構並寫一份發展建議"
- "修改 kernel.yml，讓它具備定時備份的功能"
